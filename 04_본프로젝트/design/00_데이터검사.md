**환승역에서 승하차·승강기가 한 호선 코드로만 기록된다.**

| 역 | 승하차 | 승강기 |
|---|---|---|
| 충무로 3호선(321) / 4호선(423) | 321은 20일, 노인 승차 0 → 423에 합산된 것으로 보임 | 321에 승강기 0대 |
| 연신내 3호선(311) / 6호선(2615) | 2615는 23일, 노인 승차 0 | |

| 신내 6호선(2649) | 2일 | |
| 까치울(2753), 상동(2758) 7호선 | 각 1일 | 승강기 0대 (서울교통공사 관리 구간 밖으로 보임) |

역 단위 분석(질문 3)을 호선별 역(station)으로 하면 환승역 한쪽이 0으로 나와 왜곡된다. 처리 방안:

1. **역사(驛舍) 단위 묶음 추가** — STATION에 역사 식별자(예: 같은 역명이면 같은 역사)를 두거나 STATION_COMPLEX 테이블을 분리하고, 분석은 역사 단위로 집계한다. `01_기획/08_1031_ER모델_검토.md`의 R1(역사/노선역 분리) 의견과 같은 방향이다.
2. 데이터가 거의 없는 역(1~23일)은 분석에서 제외하고 대시보드에는 표시만 한다.
