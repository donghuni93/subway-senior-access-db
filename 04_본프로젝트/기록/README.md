## 쓰는 규칙

1. **한 날짜에 한 파일.** 같은 날 여러 번 바뀌면 같은 파일의 `변경` 표에 행을 더한다.
2. **상태는 사실대로.** `완료`는 테스트나 실행으로 확인한 것만, 확인하지 못한 것은 `진행 중`·`미확인`으로 적는다.
3. **파일은 경로로.** 바뀐 파일은 `04_본프로젝트/` 기준 경로로 적는다. 서버 수집 담당 세션의 파일(`src/collect.py` 등)을 바꿨다면 반드시 적는다.
4. **이유는 한 줄만.** 긴 이유와 대안은 `진행기록.md`에 쓰고 여기서는 링크한다.
5. **숫자는 출처와 함께.** 건수·시각은 어느 명령이나 점검에서 나온 값인지 적는다.
