# 설계 근거 추적표 (2026-11-25)

이 문서는 `subway_access_db`의 설계 결정 하나하나를 강의(00~09장)의 어느 개념으로 설명하는지 한 줄씩 대응시킨 표이다. 성능 근거가 아니라 설명 근거를 모은 것이며, 최종보고서와 발표 질의응답에서 행 번호(예: 2-6행)로 인용한다.
읽는 법: 각 행은 설계 요소 → 우리 결정 → 강의 개념(지식베이스 카드 이름) → 출처 쪽수 → 실제 예·파일 순이다. 출처 쪽수는 `00_지식베이스/raw/md/`의 `## p.N` 원문에서 직접 확인한 것만 적었다. 강의에 없는 내용은 `[강의 범위 밖: 모델 일반 지식]`으로 표시하고 6절에 모았다.
기존 문서와의 관계: 결정의 상세 이유와 수치는 `01_요구사항명세서.md`~`06_테스트.md`에 있고, 이 표는 그 결정을 강의 개념에 연결하는 색인 역할만 한다. 테이블 정의는 `03_sql/01_schema.sql`을 기준으로 하며(11/25 재검토 반영 뒤 테이블 14개, PRIMARY KEY 14개, FOREIGN KEY 12개, UNIQUE 9개, CHECK 11개), 문서와 DDL이 다르거나 확인이 필요했던 곳은 8절에 모았다(11/25에 해결, 재검토 뒤 8절은 13번 한 항목만 미해결).
