## p.6

관계 데이터 연산의 기본 개념                    관계 데이터 연산의 개념

■ 관계 대수 (Relational Algebra) 란?
 ▪ 원하는 결과를 얻기 위해 릴레이션의 처리 과정을 순서대로 기술하는 절차적 언어 (Procedural Language)
 ▪ 관계형 데이터베이스에서 원하는 정보를 어떻게 유도하는가를 기술하는 절차적 언어
  • 릴레이션이란 외형적으로 테이블을 의미
  • 릴레이션 연산: 테이블을 구성하는 Tuple (Row), Attribute (Column) 등에 대하여 어떤 조작을 가하여 결과를 얻어내는 것을 의미
 ▪ 즉, 하나 또는 두 개의 릴레이션을 받아들여 새로운 릴레이션을 생성해내는 연산들의 집합
  • 릴레이션에 대한 연산 (Select, Project, …)과 그 규칙을 다루는 데이터베이스의 한 분야

■ 관계 해석 (Relational Calculus)
 ▪ 처리를 원하는 데이터가 무엇인지만 기술하는 언어
  • 비절차 언어 (Nonprocedural Language)
 ▪ 수학의 프레디킷 해석 (Predicate Calculus)에 기반을 두고 있음
 ▪ 분류
  • 투플 관계 해석 (Tuple Relational Calculus)
  • 도메인 관계 해석 (Domain Relational Calculus)

[다이어그램: 왼쪽 파란 박스 "관계 데이터 연산"에서 두 갈래. 위 "관계 대수" - "원하는 결과를 얻기 위해 데이터의 처리 과정을 순서대로 기술", 아래 "관계 해석" - "원하는 결과를 얻기 위해 처리를 원하는 데이터가 무엇인지만 기술"]

 ▪ 결합적 특징이 있음
  • (R∪S)∪T = R∪(S∪T)

■ 일반 집합 연산자 – 카티션 프로덕트(Cartesian Product)
 ▪ 두 릴레이션 R과 S의 카티션 프로덕트 : R×S
  • 릴레이션 R에 속한 각 투플과 릴레이션 S에 속한 각 투플을 모두 연결하여 만들어진 새로운 투플로 결과 릴레이션을 구성

  • 차수는 릴레이션 R과 S의 차수를 더한 것과 같음
  • 카디널리티는 릴레이션 R과 S의 카디널리티를 곱한 것과 같음
 ▪ 교환적 특징이 있음
  • R×S = S×R
 ▪ 결합적 특징이 있음
  • (R×S)×T = R×(S×T)

확장된 관계대수                                 관계 대수

■ 확장된 관계 대수 연산자 – 외부 조인(Outer-join)

[다이어그램: "SQL JOIN" 벤 다이어그램 모음. 각 그림은 두 원 A, B와 칠해진 영역, 그리고 SQL문으로 구성됨]
- INNER JOIN (A와 B의 교집합 영역): SELECT * FROM TableA A INNER JOIN TableB B ON A.key = B.key;
- LEFT JOIN (A 전체 영역): SELECT * FROM TableA A LEFT JOIN TableB B ON A.key = B.key;
- LEFT JOIN, B에 없는 A만 (A에서 교집합 제외한 영역): SELECT * FROM TableA A LEFT JOIN TableB B ON A.key = B.key WHERE B.Key IS NULL;
- RIGHT JOIN (B 전체 영역): SELECT * FROM TableA A RIGHT JOIN TableB B ON A.key = B.key;
- RIGHT JOIN, A에 없는 B만 (B에서 교집합 제외한 영역): SELECT * FROM TableA A RIGHT JOIN TableB B ON A.key = B.key WHERE A.Key IS NULL;
- FULL OUTER JOIN (A와 B 전체 영역): SELECT * FROM TableA A LEFT JOIN TableB B UNION SELECT * FROM TableA A RIGHT JOIN TableB B
- FULL OUTER JOIN, 교집합 제외 (A와 B에서 교집합만 뺀 영역): SELECT * FROM TableA A LEFT JOIN TableB B UNION SELECT * FROM TableA A RIGHT JOIN TableB B WHERE A.key IS NULL OR B.key IS NULL
