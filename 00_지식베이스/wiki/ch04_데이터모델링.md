# 04장 데이터모델링
## 학습 목표
- 데이터 모델링과 데이터 모델의 개념을 이해한다.
- 개념적 데이터 모델인 "개체 – 관계" 모델을 이용해 모델링을 하는 방법을 익힌다.
- "개체 - 관계 " 모델을 "개체 - 관계 다이어그램"으로 작성하는 방법을 익힌다.
- 논리적 데이터 모델의 종류와 특징을 이해한다. (p.2)

## 핵심 요약
- 데이터 모델링은 현실 세계의 데이터를 컴퓨터 세계의 데이터베이스로 옮기는 변환 과정이며 DB 설계의 핵심이다. 추상화를 거친다. (p.4)
- 2단계 모델링: 개념적 모델링(현실 -> 개념 세계) 후 논리적 모델링(개념 -> 컴퓨터 세계). (p.5)
- 데이터 모델은 데이터 구조(정적) + 연산(동적) + 제약조건으로 구성된다. 개념적 모델은 E-R 모델, 논리적 모델은 관계 모델. (p.6-7)
- E-R 모델은 피터 첸(1976)이 제안, 핵심 요소는 개체·속성·관계. 강의는 IE의 crow's foot 표기를 쓴다. (p.9)
- 개체는 사각형, 개체 타입은 이름+속성 정의, 개체 인스턴스는 속성이 값을 가진 것, 개체 집합은 인스턴스 모음. (p.11-13)
- 속성은 타원. 단일/다중(이중 타원), 단순/복합, 유도(점선 타원)로 분류하고, 널 속성과 키 속성(밑줄)이 있다. (p.14-21)
- 관계는 마름모. 참여 개체 수로 이항·삼항·순환, 최대 카디널리티로 1:1·1:N·N:M으로 나눈다. (p.23-31)
- 관계의 참여는 필수적(이중선, 수직 막대)과 선택적(원)이며 최소 카디널리티 1/0에 대응한다. (p.32-34)
- 약한 개체는 강한 개체에 의존하며 이중 사각형·이중 마름모. ID-종속 개체는 모두 약하지만 역은 아님. (p.35-38)
- 슈퍼타입/서브타입(IS-A), 판별자, exclusive/inclusive. (p.39-41)
- E-R 다이어그램: 사각형=개체, 마름모=관계, 타원=속성, 연결선, 1:1/1:N/N:M 레이블. 예: 고객-구매-책-공급-출판사. (p.42-43)
- 논리적 데이터 모델은 계층(트리, 1:n만), 네트워크(그래프, 오너/멤버 1:n만), 관계(2차원 테이블)로 나뉜다. 계층·네트워크는 n:m 직접 표현 불가. (p.45-48)
- Highline University 사례에서 보고서들로부터 COLLEGE, DEPARTMENT, PROFESSOR, STUDENT, APPOINTMENT 개체와 관계를 점진적으로 도출한다. (p.50-60)

## 시험·과제 포인트
- 강의가 예제로 다룬 것: 고객-구매-책-공급-출판사 E-R 다이어그램(p.43), 남편-아내 1:1, 부서-사원 1:N, 고객-책 N:M(p.28-31). (p.28-31, p.43)
- 속성 분류 예: 연락처(다중 값), 주소·생년월일(복합), 판매가격·나이(유도). (p.17-19)
- 약한 개체 예: 직원-부양-부양가족. 서브타입 예: PATIENT(MALE, FEMALE), EMPLOYEE(MANAGER, DB_ADMIN). (p.35, p.39-40)
- 케이스 스터디: DEPARTMENT/PROFESSOR 관계의 4가지 대안(N:M, 1:N, 연관 패턴, 1:1 추가)과 최종 HU 모델. (p.52-60)
