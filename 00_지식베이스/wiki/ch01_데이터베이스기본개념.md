# 01장 데이터베이스 기본 개념

## 학습 목표
- 데이터와 정보의 차이를 이해한다. (p.2)
- 데이터베이스의 필요성을 알아본다. (p.2)
- 데이터베이스의 정의에 숨겨진 의미와 주요 특징을 이해한다. (p.2)

## 핵심 요약
- 데이터는 관찰·측정으로 수집한 사실이나 값이고, 정보는 의사 결정에 유용하도록 데이터를 처리한 결과물이다. 정보 처리는 데이터에서 정보를 추출하는 과정이다. (p.4)
- 정보 시스템은 데이터를 수집·저장했다가 필요할 때 정보를 만들어 주는 수단이며, 데이터베이스는 그 안에서 데이터를 저장·제공한다. (p.8)
- 파일 시스템은 1960년대부터 사용되었고 응용 프로그램마다 별도 파일을 조직한다. (p.9-10)
- 파일 처리의 문제점은 데이터 중복성, 불일치, 무결성 침해, 표준화의 어려움, 종속성, 보안의 어려움이다. (p.15)
- 데이터 종속성: 프로그램 구조가 파일 구조의 영향을 받아 개발·유지 보수가 어렵다. (p.12)
- 데이터 중복성은 저장 공간 낭비와 불일치, 보안 문제를 일으키고, 무결성은 데이터 형식·범위 준수의 성질이다. (p.13)
- 데이터베이스는 조직의 여러 사용자가 공유하도록 통합해서 저장한 운영 데이터의 집합으로 통합·공유·저장·운영 데이터의 네 요소를 가진다. (p.18)
- 데이터베이스의 특징은 실시간 접근, 계속 변화, 동시 공유, 내용 기반 참조이다. (p.19)
- 데이터베이스의 장점은 독립성, 무결성, 중복·불일치 최소화, 표준화, 보안, 공유 용이이다. (p.20)
- 형태에 따라 정형·반정형·비정형으로, 특성에 따라 범주형(명목·순서)·수치형(이산·연속)으로 데이터를 분류한다. (p.22-30)
- 관계형 데이터베이스는 관련된 테이블의 집합이며 Codd의 1970년 논문에서 비롯되었고, SQL로 What만 기술한다. (p.32-35)
- 메타데이터는 데이터에 대한 데이터로, DB는 자기 자신의 설명을 저장한다(자기 기술적). (p.32, 36)

## 시험·과제 포인트
- 한빛 인터넷 쇼핑몰 주문 내역(데이터) -> 제품별 총 판매액(정보) 예제. (p.4)
- 종속성 예: 이름 필드 20->30자리 변경, 필드 순서 변경(COBOL 학생정보 파일). (p.12)
- 무결성 예: 나이 필드는 숫자·양수, 범위 20~60. (p.13)
- 불일치 예: 주소 변경 통보, 휴학생에게 등록금 고지서 발송. (p.14)
- 내용 기반 참조 예: 재고량 1,000개 이상인 제품 이름 검색. (p.19)
- 데이터 분류별 예시(명목: 성별·혈액형, 순서: 학년·학점·회원 등급, 이산: 고객 수, 연속: 키·몸무게). (p.27-29)
- STUDENT/CLASS/GRADE 테이블 예와 USER_TABLES/USER_COLUMNS 메타데이터 예. (p.35-36)
- 참고: p.5-7, 33은 'Recent Update' 슬라이드(DIKW, 데이터 vs 정보 중요도, Codd 논문 요약)로 외부 요약 성격이다.
