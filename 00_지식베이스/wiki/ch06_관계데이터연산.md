# 06장 관계 데이터 연산

## 학습 목표
- 관계 데이터 연산의 개념과 종류를 알아본다.
- 일반 집합 연산자와 순수 관계 연산자의 차이를 이해한다.
- 일반 집합 연산자와 순수 관계 연산자를 이용해 질의를 표현하는 방법을 익힌다. (p.2)

## 핵심 요약
- 데이터 모델 = 데이터 구조 + 연산 + 제약조건. 관계 데이터 연산은 원하는 데이터를 얻기 위해 릴레이션에 처리 요구를 수행하는 것이다. (p.4-5)
- 관계 대수와 관계 해석은 기능·표현력이 동등하며, 이로 기술 가능한 모든 질의를 기술하는 데이터 언어는 관계적으로 완전하다. (p.5)
- 관계 대수는 처리 과정을 순서대로 기술하는 절차 언어, 관계 해석은 원하는 데이터가 무엇인지만 기술하는 비절차 언어(투플/도메인 관계 해석)이다. (p.6)
- 관계 대수는 대표 연산자 8개를 가지며 폐쇄 특성(피연산자도 결과도 릴레이션)이 있다. 일반 집합 연산자(∪, ∩, −, ×)와 순수 관계 연산자(σ, π, ⋈, ÷)로 분류한다. (p.10-11)
- 합집합·교집합·차집합은 합병 가능(차수 같음, 대응 속성 도메인 같음)한 릴레이션끼리만 연산한다. 합집합·교집합은 교환적·결합적, 차집합은 둘 다 아니다. (p.13-16)
- 카티션 프로덕트는 차수를 더하고 카디널리티를 곱한다. (p.18)
- 셀렉트 σ는 수평적, 프로젝트 π는 수직적 연산자이며, 프로젝트 결과에서 중복 투플은 한 번만 나타난다. (p.20, p.24-25)
- 조인은 조인 속성 값이 같은 투플을 연결한다. 세타 조인은 θ가 비교 연산자, 동등 조인은 θ가 "=", 자연 조인은 동등 조인에서 중복된 조인 속성을 제거한다. (p.30-35)
- 디비전 R ÷ S는 S의 모든 투플과 관련이 있는 R의 투플로 구성한다. (p.36-38)
- 여러 연산자를 결합해 질의를 만들 수 있고(π∘σ, 조인 포함, 차집합), 이름 붙이기에는 ρ와 ←를 쓴다. (p.27-29, p.39)
- 확장 연산자: 세미 조인(⋉)은 조인 속성으로 프로젝트한 릴레이션을 이용하고 교환적이지 않다. 외부 조인은 자연 조인에서 제외되는 투플도 널 값과 함께 포함하며 왼쪽·오른쪽·완전으로 나뉜다. (p.40-48)
- SQL의 SELECT-FROM-WHERE와 DISTINCT, 조인, 집계함수(sum, count, avg, min, max, group by)가 관계 대수 식과 대응된다. (p.50-54)
