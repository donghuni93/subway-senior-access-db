# 02장 데이터베이스 관리 시스템

## 학습 목표
- 파일 시스템의 문제점과 데이터베이스 관리 시스템의 필요성을 알아본다. (p.2)
- 데이터베이스 관리 시스템의 필수 기능을 살펴본다. (p.2)
- 데이터베이스 관리 시스템의 장단점을 알아본다. (p.2)
- 데이터베이스 관리 시스템의 발전 과정을 살펴본다. (p.2)

## 핵심 요약
- 파일 시스템은 응용 프로그램별로 별도 파일을 관리하며 중복, 종속, 동시 공유·보안·회복 부족, 개발 곤란의 문제가 있다. (p.4)
- 중복은 저장 공간 낭비와 일관성·무결성 유지 곤란을 낳고(p.5), 파일 구조가 바뀌면 응용 프로그램도 바뀌어야 한다(종속성). (p.7)
- DBMS는 파일 시스템의 문제를 해결하기 위한 소프트웨어로, 데이터를 통합 저장·관리한다. (p.9)
- DBMS의 주요 기능은 정의·조작·제어 기능이다. (p.10)
- 주요 구성 요소는 질의 처리기와 저장 데이터 관리자이다. (p.11)
- 장점: 중복 통제, 독립성, 동시 공유, 보안 향상, 무결성 유지, 표준화, 장애 회복, 개발 비용 감소. (p.13-14)
- 단점: 비용, 복잡한 백업·회복, 중앙 집중 관리의 취약점. (p.15)
- 1세대는 계층 DBMS(트리, 예 IMS)와 네트워크 DBMS(그래프, 예 IDS)이다. (p.17)
- 2세대는 관계 DBMS(테이블), 3세대는 객체지향 DBMS와 객체관계 DBMS이다. (p.20)
- 4세대는 NoSQL(비정형·확장성, 일관성 기능 포기)과 NewSQL(관계 DBMS의 장점 + NoSQL의 확장성)이다. (p.24)
- 발전 순서: 파일 시스템(1960년) -> 1세대 -> 2세대 -> 3세대 -> 4세대. (p.26)
