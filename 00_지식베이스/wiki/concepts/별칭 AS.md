## 정의
AS 키워드를 이용해 결과 테이블에서 속성의 이름을 바꾸어 출력한다. AS는 생략 가능하다.

## 핵심 내용
- 새 이름에 공백이 있으면 큰따옴표나 작은따옴표로 묶는다. 오라클은 큰따옴표, MS SQL 서버는 작은따옴표를 사용한다 (p.37).
- FROM 절에서 테이블 이름을 대신하는 단순한 별명을 제시할 수도 있다 (p.74).

## 예시
```sql
SELECT 제품명, 단가 AS 가격 FROM 제품;   -- 7-16
SELECT o.주문제품, o.주문일자 FROM 고객 c, 주문 o
WHERE c.나이 >= 30 AND c.고객아이디 = o.주문고객   -- p.74
```

## 흔한 실수/혼동
- 공백이 포함된 별칭은 따옴표가 필요하고 DBMS마다 따옴표 종류가 다르다.
