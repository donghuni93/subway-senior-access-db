## 정의
SELECT 절에 속성 이름과 +, -, *, / 산술 연산자와 상수로 이루어진 산술식을 제시해 계산 결과를 검색한다.

## 핵심 내용
- 결과 테이블에서만 계산된 값이 출력되며 속성의 실제 값이 변경되는 것은 아니다.

## 예시
```sql
SELECT 제품명, 단가 + 500 AS "조정 단가" FROM 제품;   -- 7-17
```
결과: 그냥만두 5000, 매운쫄면 6000, 쿵떡파이 3100, 맛난초콜릿 3000, 얼큰라면 1700, 통통우동 2050, 달콤비스킷 2000

## 흔한 실수/혼동
- 값을 실제로 바꾸려면 UPDATE ... SET 단가 = 단가 * 1.1 (7-50)을 쓴다.
