## 정의
릴레이션 스키마에 대한 설계 정보를 기술한 문서. 변환 후 속성의 데이터 타입과 길이, 널 값 허용 여부, 기본값, 제약조건 등을 세부적으로 결정하고 문서화한 것 (p.63).
## 핵심 내용
- 열 구성: 속성 이름, 데이터 타입, 널 허용 여부, 기본값, 기본키, 외래키, 제약조건.
- 이 명세서를 바탕으로 5단계에서 SQL 문을 작성한다 ([[구현]], p.71).
## 예시
그림 8-48 회원 릴레이션 (p.63):
| 속성 이름 | 데이터 타입 | 널 허용 | 기본값 | 기본키 | 제약조건 |
|---|---|---|---|---|---|
| 회원아이디 | VARCHAR(20) | N | | PK | |
| 비밀번호 | VARCHAR(20) | N | | | |
| 이름 | VARCHAR(10) | N | | | |
| 나이 | INT | Y | | | 0 이상 |
| 직업 | VARCHAR(20) | Y | | | |
| 등급 | VARCHAR(10) | N | silver | | silver, gold, vip만 허용 |
| 적립금 | INT | N | 0 | | |
(외래키 열은 회원 릴레이션에서 모두 비어 있음)
## 흔한 실수/혼동
원문에는 회원 릴레이션 하나의 명세서만 제시되어 있다.
