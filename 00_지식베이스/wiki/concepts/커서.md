## 정의
수행 결과로 반환된 여러 행을 한 번에 하나씩 가리키는 포인터. 여러 행을 반환하는 SELECT를 프로그램에서 쓸 때 필요하다.

## 핵심 내용
- DECLARE: EXEC SQL DECLARE 커서_이름 CURSOR FOR SELECT 문;
- OPEN: EXEC SQL OPEN 커서_이름; (SELECT 실행)
- FETCH: EXEC SQL FETCH 커서_이름 INTO 변수_리스트; 다음 행으로 이동해 값을 변수에 저장. 여러 행이므로 반복문과 함께 여러 번 수행
- CLOSE: EXEC SQL CLOSE 커서_이름;

## 예시
```c
EXEC SQL DECLARE product_cursor CURSOR FOR SELECT 제품명, 단가 FROM 제품;
EXEC SQL OPEN product_cursor;
EXEC SQL FETCH product_cursor INTO :p_name, :price;
EXEC SQL CLOSE product_cursor;
```

## 흔한 실수/혼동
- 원문 p.126의 예시는 커서 이름이 'procuct_cursor'로 오타 표기되어 있다.
