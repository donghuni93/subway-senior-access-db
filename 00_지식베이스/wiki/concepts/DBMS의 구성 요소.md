## 정의
DBMS의 주요 구성 요소는 질의 처리기와 저장 데이터 관리자이다.

## 핵심 내용
- 질의 처리기(query processor): 사용자의 데이터 처리 요구를 해석하여 처리. DDL 컴파일러, DML 프리 컴파일러, DML 컴파일러, 런타임 데이터베이스 처리기, 트랜잭션 관리자 등을 포함
- 저장 데이터 관리자(stored data manager): 디스크에 저장된 데이터베이스와 데이터 사전을 관리하고 접근
- 입력: 데이터베이스 관리자(데이터 정의어), 최종 사용자(데이터 조작어), 응용 프로그래머(응용 프로그램)

## 예시
그림: DBA -> DDL 컴파일러, 최종 사용자 -> DML 컴파일러, 응용 프로그래머 -> DML 프리 컴파일러 -> 런타임 DB 처리기(+트랜잭션 관리자) -> 저장 데이터 관리자 -> 데이터 사전, 데이터베이스.

## 흔한 실수/혼동
- 데이터 사전은 DBMS 안의 저장 데이터 관리자가 접근하는 대상이다.
