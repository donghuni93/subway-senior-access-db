## 정의
특정 속성 값을 통계적으로 계산해 검색하는 함수. 열 함수(Column Function)라고도 하며 개수, 합계, 평균, 최댓값, 최솟값 계산을 제공한다.

## 핵심 내용
- COUNT 속성 값의 개수(모든 데이터), MAX 최댓값(모든 데이터), MIN 최솟값(모든 데이터), SUM 합계(숫자), AVG 평균(숫자) (표 7-6)
- 집계 함수는 널인 속성 값을 제외하고 계산한다.
- 집계 함수는 WHERE 절에서 사용할 수 없고 SELECT 절이나 HAVING 절에서만 사용할 수 있다.
- 정확한 개수를 세려면 보통 기본키 속성이나 *를 이용한다 (p.61).

## 예시
```sql
SELECT AVG(단가) FROM 제품;   -- 7-28: 2764.2857...
SELECT SUM(재고량) AS "재고량 합계" FROM 제품 WHERE 제조업체 = '한빛제과';   -- 7-29: 6500
SELECT COUNT(고객아이디) AS 고객수 FROM 고객;   -- 7
SELECT COUNT(나이) AS 고객수 FROM 고객;         -- 6 (널 제외)
SELECT COUNT(*) AS 고객수 FROM 고객;            -- 7
SELECT COUNT(DISTINCT 제조업체) AS "제조업체 수" FROM 제품;   -- 7-31: 3
```

## 흔한 실수/혼동
- COUNT(나이)는 NULL을 세지 않아 6, COUNT(*)·COUNT(고객아이디)는 7.
- 집계 조건을 WHERE에 쓰면 안 된다(HAVING 사용).
