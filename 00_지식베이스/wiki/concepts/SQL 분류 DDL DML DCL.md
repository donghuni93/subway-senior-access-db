## 정의
SQL은 데이터 정의어(DDL), 데이터 조작어(DML), 데이터 제어어(DCL)로 분류한다.

## 핵심 내용
- DDL(Data Definition Language): 테이블을 생성하고 변경·삭제. CREATE TABLE / ALTER TABLE / DROP TABLE (p.8)
- DML(Data Manipulation Language): 새 데이터 삽입, 저장된 데이터 수정·삭제·검색. SELECT(검색) / INSERT(삽입) / UPDATE(수정) / DELETE(삭제) (p.28)
- DCL(Data Control Language): 보안을 위해 데이터 접근·사용 권한을 사용자별로 부여하거나 취소 (p.5)
