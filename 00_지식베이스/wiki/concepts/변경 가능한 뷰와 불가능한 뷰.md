## 정의
뷰에 대한 삽입·수정·삭제 연산은 실제로 기본 테이블에 수행되며 제한적으로만 가능하다. 변경 가능한 뷰와 불가능한 뷰로 나뉜다.

## 핵심 내용
- 변경 불가능한 뷰의 특징: 기본키 속성이 포함되지 않은 뷰 / 기본 테이블에서 NOT NULL인 속성이 포함되지 않은 뷰 / 집계 함수로 새로 계산된 내용을 포함 / DISTINCT 포함 / GROUP BY 포함 / 여러 테이블을 조인한 뷰는 변경 불가능한 경우가 많음

## 예시
```sql
CREATE VIEW 제품1 AS SELECT 제품번호, 재고량, 제조업체 FROM 제품 WITH CHECK OPTION;
INSERT INTO 제품1 VALUES ('p08', 1000, '신선식품');   -- 7-58 성공, 제품 테이블에 (p08, NULL, 1000, NULL, 신선식품) 삽입
CREATE VIEW 제품2 AS SELECT 제품명, 재고량, 제조업체 FROM 제품 WITH CHECK OPTION;
INSERT INTO 제품2 VALUES ('시원냉면', 1000, '신선식품');   -- 실패: 기본키 제품번호가 NULL이 됨
```

## 흔한 실수/혼동
- 제품1(기본키 포함)은 삽입 가능, 제품2(기본키 없음)는 삽입 실패.
