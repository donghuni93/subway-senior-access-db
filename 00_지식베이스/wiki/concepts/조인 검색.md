## 정의
여러 개의 테이블을 연결하여 데이터를 검색하는 것. 테이블을 연결해주는 속성을 조인 속성이라 한다.

## 핵심 내용
- 조인 속성 이름은 달라도 되지만 도메인은 같아야 하며, 일반적으로 외래키를 조인 속성으로 이용한다.
- FROM 절에 필요한 모든 테이블을 나열하고, WHERE 절에 조인 속성 값이 같다는 조인 조건을 제시한다.
- 같은 이름의 속성이 여러 테이블에 있을 수 있으므로 속성 이름 앞에 테이블 이름을 쓴다(예: 주문.주문고객).
- 표준 SQL은 INNER JOIN ... ON 형식도 제공한다 (p.76).

## 예시
```sql
SELECT 제품.제품명 FROM 제품, 주문
WHERE 주문.주문고객 = 'banana' AND 제품.제품번호 = 주문.주문제품;   -- 7-37: 그냥만두, 맛난초콜릿, 통통우동

SELECT 주문.주문제품, 주문.주문일자 FROM 고객 INNER JOIN 주문 ON 고객.고객아이디 = 주문.주문고객 WHERE 고객.나이 >= 30;   -- p.76 (7-38)
```
7-39는 3개 테이블(고객, 제품, 주문) 조인: 고명석 -> 매운쫄면, 쿵떡파이.

## 흔한 실수/혼동
- 조인 조건을 빠뜨리면 안 된다(강의에서 모든 조인 예제가 조인 조건을 WHERE/ON에 둠).
