## 정의
관계 데이터 모델의 연산. 원하는 데이터를 얻기 위해 릴레이션에 필요한 처리 요구를 수행하는 것. (p.5)

## 핵심 내용
- 데이터 모델 = 데이터 구조 + 연산 + 제약조건 (p.4)
- 종류: 관계 대수와 관계 해석. 기능과 표현력 측면에서 동등한 능력 (p.5)
- 역할: 데이터 언어의 유용성을 검증하는 기준 (p.5)
- 관계 대수나 관계 해석으로 기술할 수 있는 모든 질의를 기술할 수 있는 데이터 언어는 관계적으로 완전(Relationally Complete)하다고 판단 (p.5)
- 질의(Query): 데이터에 대한 처리 요구 (p.5)
- 대표 연산자와 기호(p.8): Projection π, Selection σ, Renaming ρ, Union ∪, Intersection ∩, Assignment ←, Cartesian product ×, Join ⋈

## 예시
관계 대수 개념도 (p.7): 입력 릴레이션 하나가 단항 관계 연산자를 거치거나, 입력 릴레이션 둘이 이항 관계 연산자를 거쳐 결과 릴레이션이 된다. 표 3개(class_no/title, class/id, id/name/grade) 위에 조인, 프로젝트(name 열), 셀렉트(id 30·40 행) 범위를 표시한 그림이 있다.
사용예 (p.8): π_Namn ( σ_Medlemsnummer < 3 ( Medlem ) )

## 흔한 실수/혼동
- 관계 대수와 관계 해석은 표현 방식이 다를 뿐 능력은 동등하다. (p.5)
- p.8 연산자 분류도(Basic: Set Difference, Cartesian Product, Rename, Select, Project, Union / Derived: Division, Intersection, Join)는 p.11의 "일반 집합 연산자 / 순수 관계 연산자" 분류와 기준이 다르다.
