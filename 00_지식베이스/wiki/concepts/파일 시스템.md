## 정의
파일은 같은 유형의 데이터 모음이며, 파일의 조직은 특정한 정보처리의 목적을 달성하기 위해 구축한다. 파일 시스템은 1960년대부터 사용되었고 각 응용 프로그램마다 별도의 파일을 조직한다.

## 핵심 내용
- 파일 처리의 개념: Flat File (p.9)
- 컴퓨터 발전사(p.10): 1세대(~1950년대 초반, 기술 계산·자료 분류), 2세대(1950년대, 운영체제 도입, FORTRAN·COBOL 개발), 파일 시스템 도입(1960년대)
- 파일 처리의 위기(p.11): 중복 데이터·불일치, 공유 부족으로 새 프로그램마다 새 파일 구성, 활용도·생산성 저하, 보안 미흡, 회복 어려움
- 02장 p.4: 파일을 생성·삭제·수정·검색하는 기능을 제공하는 소프트웨어로 정의

## 예시
부서별 파일: 판매파일-마케팅부, 재고파일-생산부, 고객파일-고객서비스부, 자금파일-회계부, 사원파일-인사부.
사원 파일의 레코드: 이름 | 사원 ID | 소속부서 | 주소 | 전화번호 (필드 예: 이름).
응용 프로그램 1~4가 필요한 데이터 A~E를 각각 따로 가짐(p.11).

## 흔한 실수/혼동
