## 정의
WHERE 키워드와 함께 비교 연산자와 논리 연산자로 검색 조건을 제시해 조건을 만족하는 데이터만 검색한다.

## 핵심 내용
- 비교 연산자(표 7-2): = 같다, <> 다르다, < 작다, > 크다, <= 작거나 같다, >= 크거나 같다
- 논리 연산자(표 7-3): AND 모든 조건 만족, OR 한 가지만 만족해도, NOT 조건을 만족하지 않는 것
- 숫자뿐 아니라 문자·날짜 값도 비교할 수 있고('A' < 'C', '2022-12-01' < '2022-12-02'), 문자·날짜 값은 작은따옴표로 묶는다.

## 예시
```sql
SELECT 제품명, 재고량, 단가 FROM 제품 WHERE 제조업체 = '한빛제과';   -- 7-18: 쿵떡파이/맛난초콜릿/달콤비스킷
SELECT 주문제품, 수량, 주문일자 FROM 주문 WHERE 주문고객 = 'apple' AND 수량 >= 15;   -- 7-19: p03, 22, 22/03/15
SELECT 주문제품, 수량, 주문일자, 주문고객 FROM 주문 WHERE 주문고객 = 'apple' OR 수량 >= 15;   -- 7-20: 8행
SELECT 제품명, 단가, 제조업체 FROM 제품 WHERE 단가 >= 2000 AND 단가 <= 3000;   -- 7-21: 쿵떡파이 2600, 맛난초콜릿 2500
```

## 흔한 실수/혼동
- '다르다'는 <> 로 표기한다.
- AND와 OR 결과가 달라지는 점: 7-19는 1행, 7-20은 8행.
