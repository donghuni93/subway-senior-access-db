## 정의
LIKE 키워드로 부분적으로 일치하는 문자열 데이터를 검색한다. 문자열을 이용하는 조건에만 사용할 수 있다.

## 핵심 내용
- % : 0개 이상의 문자(내용·개수 무관), _ : 1개의 문자(내용 무관) (표 7-4)
- '데이터%' 데이터로 시작 / '%데이터' 데이터로 끝남 / '%데이터%' 포함 / '데이터___' 데이터로 시작하는 6자 / '__한%' 세 번째 글자가 한 (표 7-5)

## 예시
```sql
SELECT 고객이름, 나이, 등급, 적립금 FROM 고객 WHERE 고객이름 LIKE '김%';   -- 7-22: 김선우, 김용욱
SELECT 고객아이디, 고객이름, 등급 FROM 고객 WHERE 고객아이디 LIKE '_____';   -- 7-23: apple, melon, peach
```

## 흔한 실수/혼동
- _ 는 정확히 한 글자, % 는 0개 이상이다. 7-23은 밑줄 5개로 '5자 아이디'를 찾는다.
