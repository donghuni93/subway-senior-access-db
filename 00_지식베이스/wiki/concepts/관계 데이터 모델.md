## 정의
개념적 구조를 논리적 구조로 표현하는 논리적 데이터 모델. 하나의 개체에 대한 데이터를 하나의 릴레이션(테이블)에 저장한다.
## 핵심 내용
- 데이터 모델 = 데이터 구조 + 연산 + 제약조건(p.4).
- 1970년 소개, E.F. Codd(IBM 엔지니어)가 만들었고 '관계 대수(relational algebra)'라는 수학을 사용.
- 지금은 상용 DBMS 제품의 표준 모델.
- 강의의 핵심 용어 목록(p.9): Entity, Relation, Functional Dependency, Determinant, Candidate Key, Composite Key, Primary Key, Surrogate Key, Foreign Key, Referential Integrity Constraint, Normal Form, Multivalued Dependency.
## 예시
SKU_DATA와 ORDER_ITEM 두 테이블을 그대로 둘지 하나로 합칠지 질문하며 시작(p.5).
## 흔한 실수/혼동
Codd는 1970, 개체-관계 모델의 Chen은 1976(4장 p.9).
