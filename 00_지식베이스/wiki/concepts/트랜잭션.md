## 정의
하나의 작업을 수행하는 데 필요한 데이터베이스 연산들을 모아놓은 것 (p.76). 별첨 자료(p.75)로 수록되어 있다.
## 핵심 내용
- 작업 수행에 필요한 SQL 문들의 모임. 특히 데이터베이스를 변경하는 INSERT, DELETE, UPDATE 문의 실행을 관리 (p.76).
- 논리적인 작업의 단위이며, 장애 발생 시 복구 작업이나 병행 제어 작업을 위한 중요한 단위 (p.76).
- 무결성과 일관성 보장을 위해 필요한 연산들을 하나의 트랜잭션으로 제대로 정의·관리해야 한다 (p.76).
## 예시
계좌이체 트랜잭션 (p.77): 전 상태 성호 10,000원 / 은경 0원 → 후 성호 5,000원 / 은경 5,000원.
1. UPDATE 계좌 SET 잔액 = 잔액 - 5000 WHERE 계좌번호 = 100; (성호 인출)
2. UPDATE 계좌 SET 잔액 = 잔액 + 5000 WHERE 계좌번호 = 200; (은경 입금)
처리 순서는 중요하지 않지만 두 UPDATE 문이 모두 정상 실행되어야 한다.
