## 정의
외부 스키마는 외부 단계에서 사용자에게 필요한 데이터베이스를 정의한 것이다. 각 사용자가 생각하는 논리적 구조로 사용자마다 다르며 서브 스키마(sub schema)라고도 한다.

## 핵심 내용
- 외부 단계: 개별 사용자 관점. 하나의 DB에 외부 스키마가 여러 개 존재 가능

## 예시
관찰 DB에서 Zelda의 외부 뷰는 FISH(Species Name, Description 등)와 OBSERVATION(Date, Count, River), Bruce의 외부 뷰는 RIVER와 OBSERVATION(Date, Count, Fish).
그림 3-5: 고객 분석팀(성별, 나이, 직업), 상품 배송팀(고객번호, 고객이름, 주소, 연락처).

## 흔한 실수/혼동
- 같은 DB라도 사용자별 외부 스키마는 서로 다른 모습이다.
