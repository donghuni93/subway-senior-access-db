## 정의
데이터 모델링의 결과물을 표현하는 도구. A data model is a plan, or blueprint, for a database design.
## 핵심 내용
- 구성: 데이터 구조(정적 특징) + 연산(동적 특징) + 제약조건.
- 데이터 구조: 개념적 모델에서는 개념적 구조, 논리적 모델에서는 논리적 구조(데이터를 어떤 모습으로 저장할지).
- 연산: 개념 세계나 컴퓨터 세계에서 실제로 표현된 값들을 처리하는 작업.
- 제약조건: 데이터 무결성 유지 목적. 구조적 측면의 제약과 연산 적용 시 허용 가능한 의미적 측면의 제약.
- 개념적 데이터 모델 = 개체-관계 모델, 논리적 데이터 모델 = 관계 데이터 모델(강의 표현).
- 강의 설명: 데이터 모델은 DB 설계보다 더 일반화·추상적이며 변경하기도 더 쉽다.
## 예시
그림 4-4: 데이터 모델 - 연산(operation) / 데이터 구조(data structure) / 제약조건(constraint).
## 흔한 실수/혼동
데이터 구조=정적, 연산=동적으로 구분한다.
