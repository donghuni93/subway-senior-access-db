## 정의
데이터베이스(DB)는 특정 조직의 여러 사용자가 공유하여 사용할 수 있도록 통합해서 저장한 운영 데이터의 집합이다.

## 핵심 내용
- 통합 데이터(Integrated): 최소의 중복과 통제 가능한 중복만 허용
- 공유 데이터(Shared): 조직의 여러 사용자가 함께 소유하고 이용하는 공용 데이터
- 저장 데이터(Stored): 컴퓨터가 접근할 수 있는 매체에 저장된 데이터
- 운영 데이터(Operational): 조직의 주요 기능 수행에 지속적으로 꼭 필요한 데이터
- 개념 등장 배경: 한번 구축한 데이터를 여러 응용이 중복적으로 사용 = 통합 데이터 + 공유 데이터

## 예시
파일처리 방식은 인사부서·계좌부서·대출부서가 각자 파일을 가지고, 데이터베이스 방식은 인사부·계좌부·대출부가 DBMS를 통해 공유 데이터베이스를 사용(p.17).

## 흔한 실수/혼동
- 데이터베이스(데이터 집합)와 DBMS(그것을 관리하는 S/W)를 구분한다(p.18). 03장은 여기에 데이터베이스 시스템까지 구분한다.
