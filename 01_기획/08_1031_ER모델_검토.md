## 2. 검토 의견

### R1. "역"을 두 단계로 분리
역번호는 노선마다 따로 부여된다. 환승역(예 : 서울역 1호선 150, 4호선 426)은 역번호가 둘 이상이다. 승하차·혼잡도는 노선별 역번호 단위지만, 승강기·출입구·행정동은 물리적 역사 단위에 속할 가능성이 높다.
- 수정안 : `역사`(물리적 역, 역사ID) 1 : N `노선역`(역번호 PK, 노선, 역사ID FK)
- 승하차·혼잡도·예측은 `노선역`, 승강기·출입구 폐쇄·행정동 연결은 `역사`를 참조
- [확인 필요] 승강기 가동현황(OA-15994)이 역을 어떤 키로 식별하는지

### R2. 역명만 있는 자료를 위한 역명 대응 테이블
월별 유·무임과 일별 승하차는 역명으로만 식별된다. 사전 검토에서 역명 일치는 281개 중 211개였다.
- 수정안 : `역명_대응`(출처, 원본_노선명, 원본_역명 → 역번호 FK). 출처별 표기 차이를 한 테이블에서 관리
- 정규화 관점 : 역명은 역번호에 종속된 속성이므로 사실 테이블에 역명을 반복 저장하지 않는다

### R3. 이용 예측 테이블에 실측값을 저장하지 않음
1차안은 `이용_예측(대상일, 시간, 예측일, 예측값, 실측값)`이다. 실측값은 `시간별_승하차`에 이미 있으므로 중복 저장이고, 실측이 갱신되면 두 값이 어긋날 수 있다.
- 수정안 : `이용_예측(역번호, 대상일, 시간, 예측일, 모델구분, 예측값)`만 저장. 모델구분으로 4주 평균 기준선과 회귀·분류 모델을 같은 테이블에서 비교
- 오차는 `시간별_승하차`와 결합한 뷰(`v_예측_오차`)로 계산 — 보고서의 정규화 사례(파생 값의 중복 제거)로 쓸 수 있다

### R4. 고장 이력은 파생 테이블이지만 저장할 이유가 있음
`승강기_고장_이력`은 `승강기_상태_스냅샷`의 변화에서 만든다. 원칙적으로 파생 데이터지만, 스냅샷을 일정 기간 후 삭제하므로 이력을 따로 보존해야 한다. 이 판단을 설계 문서에 명시한다.
- PK : (승강기ID, 고장시작일). 종료일은 NULL 허용(진행 중 고장)

### R5. 노인 승하차 이력(OA-22483)과 우대권 승하차(OA-22723)를 섞지 않음
노인 이력은 "노인" 기준이고 `getStnPsgr`은 "우대권"(경로·장애·유공자 포함) 기준이다. 정의가 다르므로 같은 열에 합치면 작년 대비 비교가 왜곡된다.
- 수정안 : 별도 테이블 `노인_승하차_이력` 유지. 작년 대비 화면에서는 정의 차이를 표시

### R6. 카드구분은 엔티티로 두지 않음
적재 시 카드구분을 합산하므로 DB에는 남지 않는다. 정규화 사례 "코드명 반복 → 코드 테이블"은 `사용자구분`(일반·우대권·청소년…)으로 설명한다.

### R7. 혼잡도 방향 값
상하구분 값은 상선·하선(2호선은 내선·외선)이다. PK : (역번호, 요일구분, 방향, 시간대, 기준분기). 세로형 변환 시 전 시간대 0인 42행(종점 방향)을 둘지 정한다.

### R8. 적재 이력 참조 범위
매일 적재하는 테이블(`시간별_승하차`, `승강기_상태_스냅샷`, `출입구_폐쇄`, `이용_예측`)은 `load_log`를 FK로 참조한다. 초기 적재(노인 이력, 혼잡도)도 한 번의 적재 기록으로 남긴다.

### R9. 확장 후보 — 행정동 (제안서에는 "추후 검토"로만)
`07_1031_추가데이터후보_인구.md` 기준으로, 결합한다면 다음 구조가 된다.
- `행정동`(행정동코드 PK) — `역사_행정동`(역사ID, 행정동코드) N : M 연결 테이블
- `행정동_연령별_인구`(행정동코드, 기준분기, 연령대, 인구)
- 행정동별 지하철 승차(OA-21224, 매일 D+5)는 일자 × 행정동 × 24시간 가로형 → 세로형 변환 대상(1NF 사례 추가). 역 단위가 아니므로 역사_행정동을 거쳐야 역과 비교할 수 있다

## 3. 수정 ER 개요 (2차안, 확정 아님)

```
노선 1──< 노선역(역번호 PK) >──1 역사(역사ID PK)
              │                      ├──< 승강기 1──< 승강기_상태_스냅샷
              │                      │            └──< 승강기_고장_이력
              │                      ├──< 출입구_폐쇄
              │                      └──< 역사_행정동 >── 행정동 1──< 행정동_연령별_인구   (확장 후보)
              ├──< 시간별_승하차 (일자, 시간, 사용자구분) >── 사용자구분
              ├──< 이용_예측 (대상일, 시간, 예측일, 모델구분)
              ├──< 혼잡도 (요일구분, 방향, 시간대, 기준분기)
              ├──< 노인_승하차_이력 (일자, 시간)
              ├──< 월별_유무임 (사용월, 요금구분, 승하차구분)
              └──< 역명_대응 (출처, 원본_역명)
load_log ──< (매일 적재 테이블 전부)
뷰 : v_예측_오차, v_오늘_상태, v_월별_추정
```
