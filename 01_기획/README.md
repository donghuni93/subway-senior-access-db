# 01_기획 — 파일 안내

## 파일명 규칙

`번호_MMDD_종류_핵심내용.md`
- 번호는 작성 순서다. 새 메모는 마지막 번호 다음(07, 08 …)으로 추가한다.
- `00`은 계속 갱신하는 문서다.
- 이전 메모를 고쳐 쓰지 않고, 새 메모를 추가한 뒤 아래 표에서 이전 메모의 상태를 "대체됨"으로 바꾼다.
