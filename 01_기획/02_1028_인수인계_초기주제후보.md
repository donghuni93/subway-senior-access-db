## 1. 과제 한 줄 요약
공공데이터로 DB를 설계하고, SQL 질의 결과를 분석·시각화해서 **특정 도메인에 필요한 정보를 만들어 내는 정보시스템**을 구현한다.
- 원문: `참고자료/프로젝트 제안서-보고서_2026-1.pdf`

## 3. 필수 요구사항 (체크리스트)
- [ ] **공공 데이터** 사용 (예: data.go.kr, data.gov)
- [ ] 흐름: **SQL 질의(데이터 도출) → 분석 모델링(AI·기계학습 등) → 시각화 → 정보 도출**
- [ ] **삽입 SQL(Embedded SQL)** 사용 (예: Python 코드 안에서 SQL 실행)
- [ ] 공개 S/W 도구 권장 (MySQL Workbench, Tableau, Matplotlib 등)
- [ ] **교재 8·9장 설계 절차**: 요구사항 분석 → ER 모델링 → 정규화 검증 — **준수 항목을 제안서에 기술**
- (선택) 웹 화면 등 Front-end → 평가 시 참고(가산)
- 평가 기준: 주제의 적절성·**참신성**, 문제 규모·해결 수준, 발표·보고서

## 4. 제출물 형식
**제안서** (MS-Word, 자유 양식) — 파일명 `프로젝트-제안서-이름1-이름2.doc`
1. 프로젝트 제목(구체적으로) 및 목적
2. 수행 내용(요구사항 충족이 확인되게), 범위, 예상 결과물
3. 팀원 역할 분담 및 일정 계획

**최종보고서** — `프로젝트-최종보고서-?조.doc` + `프로젝트-증빙문서-?조.zip`
- 서론(문제 정의) / 본론(아이디어, 설계·구현·테스트) / 결론 / 참고자료
- 맨 뒷장에 1페이지 요약문(발표자료)
- zip: 소스, 실행 파일, 입력·결과 데이터

## 5. 지금까지 정한 방향
- **참신성** 위해 **최신 현황 문제**를 해결하는 주제로 하고 싶음
- 공공데이터 고를 기준: ① 여러 표로 나뉘어 서로 연결되는가(ER·정규화용) ② 수천 행 이상 ③ 최근까지 갱신

## 6. 주제 후보 (아직 미확정 — 데이터 실재 여부 확인 필요)
| 후보 | 데이터 조합 | 분석 아이디어 |
|---|---|---|
| 전기차 충전 인프라 불균형 | 충전소 현황 + 지역별 전기차 등록 | 충전소 부족 지역 예측 |
| 폭염과 전력·건강 | 기상 + 전력 수요 + 온열질환 | 폭염일 위험 예측 |
| 제조업 산업재해 | 산업재해 통계 + 업종·지역 | 재해 위험 요인 분석 (산업공학·스마트팩토리 연결) |
| 공공자전거 재배치 | 따릉이 대여·반납 + 날씨 | 대여소별 수요 예측 (물류최적화 연결) |
