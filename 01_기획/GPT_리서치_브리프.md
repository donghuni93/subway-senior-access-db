# 리서치 요청 브리프 (GPT 전달용)

> 아래 내용을 읽고, **최신 자료(기사·정부/기관 발표·통계)** 를 근거로 프로젝트 제안서의 "배경 및 문제 제기" 부분을 강화할 이슈를 찾아 주세요. 모든 수치와 주장에는 **출처(기관/매체명, 발표일, URL)** 를 붙여 주세요. 확인되지 않은 내용은 "확인 필요"로 표시해 주세요.

## 1. 프로젝트 개요

- 과목 : 대학교 3학년 '엔지니어링DB' 텀프로젝트 (2인 1조, 제안서 2026-11-03 제출, 최종 발표 12-03)
- 과제 : 공공데이터로 데이터베이스를 설계(요구사항 분석 → ER 모델링 → 정규화)하고, SQL 질의 → 분석 모델링(기계학습) → 시각화로 특정 사용자에게 필요한 정보를 제공하는 **정보시스템** 구현. 평가 기준은 주제의 적절성·참신성, 해결 대상 문제의 규모·해결 수준
- 주제(가제) : **고령 이용객을 배려하는, 누구나 쓰는 서울 지하철역 이용 정보 대시보드**
- 범위 : 서울교통공사 1~8호선 구간 약 280개 역

## 2. 우리가 정의한 문제

고령 승객이 많은 역·시간대에 혼잡과 승강기(엘리베이터·에스컬레이터) 고장이 겹치지만,
- 무임(우대권) 이용 정보는 월 단위로 늦게 공개되고,
- 역·시간대·사용자 유형별 일별 원천 데이터는 공개 후 약 1주일이면 사라지며,
- 승강기는 "현재 상태"만 공개되어 고장 이력이 남지 않는다.
그래서 이용자도 역 관리자도 **하루 단위로 미리 대비할 근거**가 없다.

## 3. 시스템이 제공할 정보 (대시보드 3구역)

1. 오늘의 이용객 추정 : 역·시간대별 예상 이용객, 예상 우대권(무임) 비율, 혼잡 피크, 덜 붐비는 시간
2. 월별 추정(참고) : 이번 달 누적 무임 이용 추정 vs 지난달 확정, 역별 무임 비율 순위
3. 오늘의 승강기·출입구 : 고장 승강기 위치, 최근 30일 고장 횟수, 임시 폐쇄 출입구와 대체 경로
- 사용자 : 일반 이용자, 고령·교통약자, 역 관리자

## 4. 사용하는 공공데이터 (서울 열린데이터광장)

- 서울교통공사 역별 승하차인원(일자 × 시간 × 역 × 사용자구분 : 일반/우대권/청소년 등, 매일 갱신, 약 1주 보관)
- 승강기 가동현황(매시), 출입구 임시폐쇄 공사현황(매일), 지하철 혼잡도(분기), 역별 월별 유·무임 승하차(월), 역별 일별 시간대별 노인 승하차(2021-07~2025-12)
- 참고 수치(2026년 9월, 우리가 직접 계산) : 무임 승차 비율 전체 약 19%, 상위 역 제기동 55%·경마공원 51%·도봉산 48%·동묘앞 48% (시장·산·경마장 등 "목적지형 역"에 고령 이용이 몰리는 경향)
